# Kinopoisk → Mirrors

Пользовательский скрипт для [Кинопоиска](https://www.kinopoisk.ru/), который добавляет быстрый переход на сайты-зеркала, упрощает интерфейс и автоматизирует загрузку карточек фильмов и сериалов.

[![Version](https://img.shields.io/badge/version-1.0.4-orange)](https://github.com/x0cdn/kp/blob/main/kp.user.js)
[![Userscript](https://img.shields.io/badge/userscript-Tampermonkey%20%2F%20Violentmonkey-blue)](https://github.com/x0cdn/kp/raw/refs/heads/main/kp.user.js)

## Возможности

### 1. Кнопки зеркал

Слева на странице появляется панель с быстрыми ссылками на зеркала.

- На странице фильма или сериала скрипт автоматически определяет тип материала и его ID.
- При переходе на зеркало ID и тип страницы (`film` или `series`) подставляются в адрес автоматически.
- Ссылки открываются в новой вкладке.
- На остальных страницах кнопки ведут на главные страницы зеркал.

В текущем списке 6 адресов

> Доступность сторонних зеркал может меняться. Скрипт добавляет ссылки, но не проверяет их работоспособность.

### 2. Компактная шапка

Скрипт изменяет верхнюю часть интерфейса Кинопоиска:

- скрывает крупный брендинговый блок;
- устанавливает высоту шапки навигации 72 px;
- убирает лишние отступы и фоновое изображение;
- корректирует позиционирование навигации.

Изменения применяются на страницах Кинопоиска автоматически.

### 3. Автоматическая загрузка карточек

Скрипт автоматизирует кнопку «Показать ещё» на страницах со списками фильмов и сериалов.

- При первой загрузке страницы стремится довести количество карточек до 50.
- При нажатии пользователем на «Показать ещё» запускает дополнительную загрузку до 50 карточек.
- Считает уникальные ссылки на фильмы и сериалы, чтобы отслеживать появление новых карточек.
- Ожидает подгрузку контента и прекращает попытки, если загрузка перестала продвигаться.

Ограничители автоматизации:

| Параметр | Значение |
| --- | ---: |
| Размер пачки | 50 карточек |
| Интервал проверки | 800 мс |
| Проверок ожидания после клика | 15 |
| Допустимое число неудачных ожиданий | 5 |
| Максимум кликов за один цикл | 30 |

## Установка

### 1. Установите менеджер пользовательских скриптов

Подойдёт любой совместимый менеджер:

- [Tampermonkey](https://www.tampermonkey.net/)
- [Violentmonkey](https://violentmonkey.github.io/)
- [Greasemonkey](https://www.greasespot.net/) (Firefox)

### 2. Установите скрипт

**[Установить Kinopoisk → Mirrors](https://raw.githubusercontent.com/x0cdn/kp/main/kp.user.js)**

Откройте ссылку после установки менеджера скриптов и подтвердите добавление скрипта.

### 3. Готово

Откройте или обновите [Кинопоиск](https://www.kinopoisk.ru/). Кнопки зеркал, компактная шапка и автоматическая загрузка карточек будут работать без дополнительной настройки.

## Обновление

В скрипте настроено автоматическое обновление через GitHub:

- **Источник:** [kp.user.js](https://github.com/x0cdn/kp/blob/main/kp.user.js)
- **Проверка обновлений:** через установленный менеджер пользовательских скриптов.

Если автоматическое обновление отключено, откройте исходный файл и установите актуальную версию вручную.

## Совместимость

- Сайт: `kinopoisk.ru` и `www.kinopoisk.ru`.
- Браузер: современный браузер с поддержкой JavaScript и CSS-селектора `:has()`.
- Требуется расширение для пользовательских скриптов.
- Специальные разрешения не запрашиваются (`@grant none`).

## Устройство скрипта

Весь функционал разделён на три независимых модуля:

| Модуль | Назначение |
| --- | --- |
| `mirrorsModule` | Панель зеркал, определение ID и отслеживание смены URL |
| `compactHeaderModule` | Стили компактной шапки |
| `fiftyCardsModule` | Подсчёт карточек и автоматическая загрузка |
